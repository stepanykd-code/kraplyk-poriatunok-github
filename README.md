# Кожна крапля — пригода. Порятунок Краплинки

Браузерний платформер про Краплика й Краплинку від Полтавської обласної станції переливання крові. Чотири сюжетні розділи, підземелля, небесні острови, піксельні комікси й музика для кожної локації.

## Запуск

Відкрийте `index.html` у браузері. Логотип, графіка, музика й гра вже містяться в цьому файлі. Збірка та встановлення залежностей не потрібні.

- Стрілки **← →** або **A D** — рух.
- **Пробіл** або **↑** — стрибок, гребок та підйом по пагону.
- **↓** — пірнання або спуск у трубу.
- **X** або **J** — постріл після отримання лейкоцита.
- **P** або **Esc** — пауза. На телефоні працюють екранні кнопки.

Музику й звуки вмикає кнопка з динаміком. Наприкінці кожного основного розділу звучить коротка мелодія перемоги. Ліхтарі зберігають прогрес у браузері.

Зберіть 250 краплинок до зустрічі з Бароном, щоб полегшити фінальний бій.

## Публікація на GitHub Pages

1. Додайте `index.html`, `.nojekyll` і `README.md` у корінь гілки `main` вибраного репозиторію.
2. Відкрийте **Settings → Pages**. Під **Source** виберіть **Deploy from a branch**.
3. Виберіть **main** і **/(root)** та натисніть **Save**. Після розгортання посилання з’явиться на цій сторінці. [Документація GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
